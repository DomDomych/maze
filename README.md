# Генерация и прохождение лабиринта

Лабораторная работа по ООП, задание 2, вариант 2.
Консольная программа на C++20 создаёт лабиринт и находит путь между двумя клетками.
Для генерации используется поиск в глубину (DFS), для поиска пути — поиск в ширину (BFS).

## Сборка и запуск

Нужны CMake 3.16 или новее и компилятор с поддержкой C++20.

```sh
cmake -S . -B build
cmake --build build
./build/maze
```

В меню выберите генерацию, введите размеры лабиринта, затем координаты начала
и конца пути. Координаты вводятся как `строка столбец`, начиная с нуля.

Обозначения: `#` — стена, `.` — путь, `S` — начало, `E` — конец,
`B` — начало и конец совпадают.

## Тесты

После сборки:

```sh
cd build
ctest --output-on-failure
```

Используется GoogleTest. Если он не установлен, CMake скачает его при первой
сборке — потребуется интернет.

## Структура

- `core/` — хранение клеток и проходов, генерация и поиск пути.
- `cli/` — меню, ввод и вывод лабиринта.
- `tests/` — модульные и интеграционные тесты.
